## D1: 中英文/数字/单位之间不加空格

**【规则】** 单位与数字、中文与英文、中文与中文之间不加空格。

**【正确示例】**

```
50m，10kg，64Kbit/s，昇腾AI处理器
```

**【错误示例】**

```
50 m，10 kg，64 Kbit/s，昇腾 AI 处理器，中文 和英文间空格
```

**【例外】** 产品名称保留空格，例如：Atlas 350 加速卡，Atlas 800T A3 超节点服务器。

## D2: 列表项标点使用保持一致

**【规则】** 同一列表中，各列表项末尾的标点使用必须保持一致——要么全部不加句号，要么全部加句号，禁止混用。

**【正确示例】**

```
- 第一项
- 第二项
- 第三项
```

或

```
- 第一项。
- 第二项。
- 第三项。
```

**【错误示例】**

```
- 第一项。
- 第二项
- 第三项。
```

## D3: 中文文档使用全角标点

**【规则】** 中文文档（正文为中文）使用全角标点符号（，。：；！？""''（）等），禁止混用半角标点。

**【正确示例】**

```
该算子支持FP16和FP32精度，输入shape需为2D。
```

**【错误示例】**

```
该算子支持FP16和FP32精度,输入shape需为2D.
```

## D4: 数字使用半角字符

**【规则】** 文档中的数字（阿拉伯数字）使用半角字符（0-9），禁止使用全角数字（０-９）。

**【正确示例】**

```
支持最多8192个token，显存占用约256MB。
```

**【错误示例】**

```
支持最多８１９２个token，显存占用约２５６MB。
```
