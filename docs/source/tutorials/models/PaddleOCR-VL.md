# PaddleOCR-VL

This model has been discontinued since vLLM Ascend v0.30.0 and will no longer receive support or fixes in subsequent versions. For deployment, please refer to the [historical version documentation](https://docs.vllm.ai/projects/ascend/en/v0.23.0/tutorials/models/PaddleOCR-VL.html).

The [original PaddleOCR-VL 0.9B recipe](https://recipes.vllm.ai/PaddlePaddle/PaddleOCR-VL)
records pinned single-NPU 310P3 FP16 and 910B3 (A2) BF16 configurations,
recognition checks, and their separate document-layout paths. Check its tested
versions and limitations before deployment; the discontinuation above still applies.
