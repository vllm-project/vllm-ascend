The container commands below need [Ascend Docker Runtime](../../getting_started/installation.md#installation-ascend-docker-runtime) on the **host**: it is the container engine's runtime, it reads `ASCEND_VISIBLE_DEVICES` and binds the selected devices into the container. Without it the container starts with no NPU inside, so `npu-smi` reports no device. Install and verify it once per host, as described in that section. If you cannot install it on the host, use the device and driver flags in [Manual device mapping without Ascend Docker Runtime](../../getting_started/installation.md#installation-container-without-runtime).
