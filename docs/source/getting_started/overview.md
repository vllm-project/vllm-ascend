## What is vLLM Ascend?

vLLM Ascend (`vllm-ascend`) is a community-maintained hardware plugin for running vLLM on Ascend NPUs. It uses a pluggable hardware interface to decouple Ascend NPU integration from vLLM, enabling commonly used open-source models to run on Ascend hardware.
