# Doc writing guide

## Guide to Writing Model Tutorial Doc

`docs/source/_templates/Model-Deployment-Tutorial-Template.md` is a template for writing model deployment tutorials. You can copy and modify it to create new docs.

## Guide to Writing Triton Operator Docs

New Triton implementations belong under
`vllm_ascend/ops/triton/`, with their operator documents under
`vllm_ascend/ops/triton/docs/`. The `v2/` namespace is retired by the operator
layout refactor.

Use the [operator documentation template](https://github.com/vllm-project/vllm-ascend/blob/main/vllm_ascend/ops/triton/docs/triton_description_specification.md)
for the placement rules and the operator inventory before adding or moving an
operator document.

## Multi-row table headers

Use the `pymdown_multimd_table` Markdown extension for grouped table headers
instead of writing an HTML table. Put every header row before the separator:

```markdown
| Model | Graph Mode || CP ||
| ^^ | Eager | Full | PCP | DCP |
| --- | --- | --- | --- | --- |
| Example | ✅ | ✅ | ❌ | ✅ |
```

Consecutive pipes (`||`) extend the preceding cell across columns. A `^^` cell
merges with the cell above it, including in the header. Use a space (`| |`) for
an ordinary empty cell; removing that space changes the table's structure.
Inside a content tab, indent every table row by four spaces. These extensions
render on the documentation site, but GitHub's Markdown preview does not support
the merged cells.

The translation extractor keeps all header rows together as one PO entry and
omits data-only rows. Preserve pipes, blank cells, `^^`, and link targets in the
translation. This keeps model matrices out of long translation requests while
retaining their grouped headers.

## Fullscreen tables

Horizontally overflowing tables have a fullscreen action. In fullscreen view,
the table header (`<thead>`, generated by Markdown tables) stays visible during
vertical scrolling, and the first column stays visible during horizontal
scrolling. A table without `<thead>` does not freeze its first row. First-column
cells spanning multiple rows are supported, including `rowspan="0"`, which
extends to the end of the row group.

If a table's first column does not provide useful context, disable its horizontal
freezing with `data-table-sticky-column="false"`. For a Markdown table, place it
inside a wrapper as shown below. The existing `md_in_html` extension renders the
Markdown inside `markdown="1"` wrappers.

```markdown
<div markdown="1" data-table-sticky-column="false">

| Quantity | Price |
| --- | --- |
| 10 | 100 |

</div>
```

For an HTML table, add the attribute directly to `<table>`. This setting affects
only first-column freezing in fullscreen view; header freezing and normal
document layout retain their existing behavior.
