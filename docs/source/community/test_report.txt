### 📚 The doc PR

**本 PR 的内容及必要性**
本 PR 提交 Qwen2.5-Omni-7B 在单卡 Ascend 910B3 上的部署与性能测试交付报告，交付人雷成仙（@leicx_dc），包括：

测试环境与软件栈版本记录（vLLM 0.21.0 / vLLM-Ascend 0.21.0rc1/ npu-smi 25.2.0）
本次测试单curl和vLLM Benchmark的配置和命令

**是否引入面向用户的变更？**
否。本 PR 仅新增社区测试交付文档，不修改任何程序接口或运行行为。

**如何测试？**
在单张 Ascend 910B3上完成验证：
步骤：
1、部署服务所用的模型和权重类别
2、分别执行curl和vLLM Benchmark命令，并观察执行结果

- 模型选择
   Qwen2.5-Omni-7B

- 部署脚本
```
export MODEL_PATH="shared_assets/QuenchingAction/Toolchain/Model/Qwen2.5-Omni-7B"
export LOCAL_MEDIA_PATH=$HOME/.cache/vllm/assets/vllm_public_assets/


vllm serve "${MODEL_PATH}" \
--host 0.0.0.0 \
--port 8000 \
--served-model-name Qwen-Omni \
--allowed-local-media-path ${LOCAL_MEDIA_PATH} \
--trust-remote-code \
--compilation-config '{"cudagraph_mode": "FULL_DECODE_ONLY"}' \
--no-enable-prefix-caching
``` 

- 测试配置脚本或命令
curl测试命令
```
curl http://localhost:8000/v1/chat/completions   -H "Content-Type: application/json"   -H "Authorization: Bearer EMPTY"   -d '{
    "model": "Qwen-Omni",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What is the text in the illustration?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://modelscope.oss-cn-beijing.aliyuncs.com/resource/qwen.png"
            }
          }
        ]
      }
    ],
    "max_completion_tokens": 100,
    "temperature": 0.7
  }'
``` 

vLLM Benchmark的配置和命令
```
vllm bench serve \
  --backend vllm \
    --model shared_assets/QuenchingAction/Toolchain/Model/Qwen2.5-Omni-7B \
  --served-model-name Qwen-Omni \
  --port 8000 \
  --dataset-name random \
  --random-input 3500 \
  --random-output 1500 \
  --max-concurrency 20 \
  --num-prompts 80 \
  --save-result \
  --result-dir ./benchmark_results/
```
