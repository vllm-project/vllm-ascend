# Qwen3.5/Qwen3.6 GDN A5 Implementation Plan

> Historical Stage 1 plan. The implemented adapter was generalized to A2/A3/A5
> on 2026-08-29 and its preferred prefill path became the Phase 6 fused core.
> The current authoritative design is
> `docs/superpowers/specs/2026-08-29-qwen35-qwen36-gdn-fla-design.md`.
> This plan is retained only as an execution history; its goals, file names,
> operator count, and acceptance boundary must not guide new work.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an A5-only GDN inference adapter that prefers nine `fla_npu` forward operators, safely falls back to current vLLM-Ascend operators, and exposes precise selection/failure logs and smoke tests for Qwen3.5/Qwen3.6.

**Architecture:** Keep model routing, scheduler metadata, and cache ownership in `vllm_ascend/ops/gdn.py`. Add a focused `gdn_a5.py` adapter that lazily resolves operators, normalizes their contracts, probes them on scratch tensors, and composes the prefill/decode paths described by the reference example. Non-A5 and explicitly native configurations retain the current implementation unchanged.

**Tech Stack:** Python, PyTorch/torch_npu, vLLM custom-op integration, `fla_npu.ops.ascendc`, `fla_npu.ops.triton`, pytest.

**Current spec:** `docs/superpowers/specs/2026-08-29-qwen35-qwen36-gdn-fla-design.md`

## Global Constraints

- Change only the `vllm-ascend` repository.
- Target Ascend A5 / Ascend 950 and Qwen3.5/Qwen3.6 shared GDN code.
- Stage 1 supports eager ordinary prefill and single-token decode only.
- Do not implement MTP, ACL Graph, prefix cache, PCP, or DCP in this plan.
- `fla_npu` is optional at import time and is installed later in the A5 environment.
- `auto` falls back only during resolution/probing; live-request runtime errors are logged and propagated without retry.
- Do not execute `python` or `python3` commands in the current Windows workspace.
- All environment variables are defined in `vllm_ascend/envs.py`.
- Use `flash-linear-attention-npu/examples/flash_gated_delta_rule.py` as the authoritative forward ordering and layout reference.
- Local and remote branch name: `a5-gdn-qwen35-36`.
