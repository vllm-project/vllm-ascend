# FlashMLA A3 third-party sources

The A3 FlashMLA CATLASS kernel adapts `src/shared_lib` from
[TyphoonMLA in CANN ops-transformer](https://gitcode.com/cann/ops-transformer/tree/master/experimental/attention/typhoon_mla).
Its source and original copyright notices are
in `csrc/flash_mla_a3/native/catlass` in the vLLM Ascend source tree. The associated
CANN Open Software License Agreement Version 2.0 is in `LICENSE-CANN`.

The kernel also uses [CATLASS v1.0.0](https://gitee.com/ascend/catlass/releases/tag/v1.0.0) headers from commit
`ef8be58db449a7271cf260c69fb0a6e02093946a`. The associated CANN Open Software
License Agreement Version 1.0 is in `LICENSE-CATLASS`.
