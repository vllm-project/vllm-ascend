## 3. Known Issues

Some issues found during validation remain unresolved in this release, summarized as follows:

| No. | Issue | Description | Impact |
|-----|-------|-------------|--------|
| 1 | [#17415](https://github.com/vllm-project/vllm-ascend/issues/17415) | In the 0.27.0rc full-automation suite, DeepSeek-V3.1 W8A8Mix MTP shows reliability failures across multiple serving configurations: (1) with prefix caching disabled, the service starts but some inference requests fail; (2) in A3 single-node colocated PD graph mode (aclgraph_2048_2048, TPOT target 50 ms), the inference service hangs; (3) with KV Cache Pool enabled in the colocated PD deployment, the service exits after warmup when inference begins | None of the three configurations can serve continuously (request failures / service hang / process exit); the failures involve the same model, release, MTP configuration, and colocated PD serving path — root cause is under investigation |
| 2 | [#17417](https://github.com/vllm-project/vllm-ascend/issues/17417) | In the main-branch nightly, Qwen3.6-27B deployment fails during service startup / inference initialization: the `ChunkGatedDeltaRuleFwdH` operator reports an out-of-bounds access | Deployment fails to initialize and cannot accept inference requests (operator memory-bound violation); exact commits, CANN / torch_npu versions, full traceback, and minimal reproduction to be added from the nightly job |
| 3 | [#17418](https://github.com/vllm-project/vllm-ascend/issues/17418) | DeepSeek-V4-Flash-0731 with 950DT products 1P1D deployment: in a pure-decode 16K workload with 100% prefix-cache hit rate, the decode node does not reach the expected request concurrency | The service remains available, but the observed concurrency on the decode node is lower than expected for this workload; possibly related to request scheduling or another bottleneck in the prefix-cache hit path — more profiling needed; expected behavior is that the decode node sustains the configured concurrency when all prefixes hit the cache |
